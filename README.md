## Files

- `style.css` - design and responsive styling

- `assets/` - project thumbnails, demo video and profile image

## GitHub Pages
Create a repository named `sameenshahidd.github.io`, upload these files, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
