# Sameen Shahid Portfolio

Personal portfolio website for Sameen Shahid.

## Files
- `index.html` - portfolio structure
- `style.css` - design and responsive styling
- `script.js` - mobile navigation
- `resume.pdf` - add your CV here
- `images/` - add project screenshots here

## GitHub Pages
Create a repository named `sameenshahidd.github.io`, upload these files, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Add your `resume.pdf`.
3. Replace project mockups with your real screenshots if desired.
4. Update the LinkedIn URL.
